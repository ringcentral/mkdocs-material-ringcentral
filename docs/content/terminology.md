# Terminology

Official names for RingCentral products, features, and UI concepts. Use these terms consistently across all product copy, documentation, and marketing materials.

---

## Product names

Always use the full product name on first mention per document. Abbreviations are acceptable on subsequent mentions.

| Correct | Incorrect | Notes |
|---------|-----------|-------|
| **RingCentral** | Ring Central, ring central | One word, always capitalized |
| **RingEX** | RingEX™, Ring EX, RingEx | No trademark symbol in product UI |
| **App Connect** | AppConnect, App connect, app connect | Two words, both capitalized |
| **App Connect 2.0** | AppConnect 2.0, App Connect 2 | Full version on first mention |
| **RingCentral Labs** | RC Labs, Ringcentral Labs | Both words capitalized |
| **RingCX** | Ring CX, Ring cx | One word |

---

## Feature names

| Term | Use | Don't use |
|------|-----|-----------|
| **call log** | "View the call log" | "call history", "call record" |
| **call logging** | "Enable call logging" | "call tracking", "log calls" (as noun) |
| **connector** | "Add a connector" | "integration", "plugin", "adapter" |
| **contact matching** | "Contact matching finds the caller" | "contact lookup", "CRM match" |
| **CRM** | "Connect to your CRM" | "customer system", "database" |
| **manifest** | "Configure the connector manifest" | "config file", "settings file" |
| **plugin** | "Install a plugin" | "extension", "add-on" (in product context) |
| **SMS log** | "Create an SMS log" | "text log", "message log" |
| **sync** | "Sync is paused" | "synchronization" (too long in UI) |
| **voicemail drop** | "Use voicemail drop" | "pre-recorded voicemail", "ringless voicemail" |
| **webhook** | "Set up a webhook" | "web hook", "callback URL" (describe it, don't rename it) |

## UI element names

Refer to UI elements by their design system names for consistency in help documentation and internal communication.

| Element | Correct term | Don't say |
|---------|-------------|-----------|
| The orange/gradient header bar | "header" | "banner" (that's a different component) |
| The left navigation panel | "sidebar" | "left nav", "left panel" |
| The horizontal navigation strip below the header | "navigation tabs" | "top tabs", "nav bar" |
| `!!! warning` blocks | "alert" | "callout", "warning box" |
| Temporary popup messages | "toast" | "snackbar", "notification popup" |
| The sliding side panel | "drawer" | "panel", "sidebar" (different from nav sidebar) |

## Technical terms

| Term | Definition | Notes |
|------|------------|-------|
| **OAuth** | Authorization framework used for CRM authentication | All caps: OAuth, not Oauth or oauth |
| **API** | Application Programming Interface | Always spell out on first mention in user-facing docs |
| **endpoint** | A URL that receives API calls | Lowercase |
| **payload** | The data sent in an API request | OK in developer docs, avoid in user-facing copy |
| **token** | Authentication credential | Don't say "API key" when it's an OAuth token |
| **webhook** | HTTP callback when an event occurs | Lowercase, one word |
| **HTTPS** | Secure HTTP | All caps |

---

## Numbers and versions

| Situation | Format |
|-----------|--------|
| Version numbers | "App Connect 2.0" (not "v2.0" or "version 2") |
| API versions | "API v2" (lowercase v, no space before number) |
| Software versions | "1.0.3" (semantic versioning) |

---

## Abbreviations to avoid in user-facing copy

Some abbreviations are fine internally but confuse users outside RingCentral. Spell these out in all user-facing surfaces:

| Avoid | Use instead |
|-------|-------------|
| RC | RingCentral |
| CRM (first mention) | customer relationship management (CRM) |
| MCP | Model Context Protocol (MCP) |
| SSO | single sign-on (SSO) |
| 2FA | two-factor authentication |
| PII | personal information |
| ToS | Terms of Service |
