# Markdown Recipes

Pure Markdown patterns that render beautifully with the `material-ringcentral` theme. No HTML required — every recipe uses standard MkDocs Material syntax that works in any editor, renders correctly in GitHub previews, and degrades gracefully when the theme is absent.

---

## How to use these recipes

Copy any block directly into a `.md` file. All syntax here relies only on the extensions already declared in `mkdocs.yml` — `pymdownx.superfences`, `pymdownx.tabbed`, `pymdownx.details`, `admonition`, and `attr_list`.
