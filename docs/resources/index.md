## Contributing

The design system is maintained by the RingCentral Labs team and improved by contributions from product teams across the company.

**To propose a change or addition:**

1. Open a GitHub issue describing the problem or gap.
2. Reference any existing component or pattern the proposal relates to.
3. Include examples from existing product usage if available.
4. The design systems team reviews proposals at the monthly sync and responds within two weeks.

**For urgent fixes** (broken layouts, accessibility regressions, incorrect token values), open a pull request directly with a clear description and tag `@ringcentral/design-systems`.
