    Components¶

    A complete library of UI building blocks — each component is documented with usage guidelines, specifications, code examples, and accessibility requirements.

    Actions¶

    Component Description
    Buttons Primary, secondary, tertiary, icon, and destructive actions
    Menus Dropdown and context menus for grouped actions

    Inputs¶

    Component Description
    Text Input Single-line and multi-line text fields
    Select Single and multi-select dropdowns
    Checkbox & Radio Binary choices and mutually exclusive option groups
    Toggle Immediate on/off switching
    Forms Grouping inputs into validated forms

    Display¶

    Component Description
    Cards Contained content surfaces with optional actions
    Tables Structured data in rows and columns
    Lists Vertical stacks of related items
    Avatars User and entity representations
    Badges Small status labels and counts
    Chips Compact interactive tags
    Dividers Separating content regions

    Feedback¶

    Component Description
    Alerts Inline status and contextual messages
    Banners Page-level announcements and system messages
    Dialogs Modal confirmations and focused tasks
    Tooltips Supplementary information on hover/focus
    Progress Determinate and indeterminate progress indicators
    Loaders Skeleton screens and spinners

    Navigation¶

    Component Description
    Navigation Side nav, top nav, and tab bars
    Breadcrumbs Hierarchical location indicators
    Tabs In-page section switching
    Pagination Navigating across pages of content
    Accordion Collapsible content sections

    Overlay¶

    Component Description
    Drawers Side-panel overlays for extended content

    Component anatomy¶

    Every component page follows the same structure:

    1. Overview — what it is and when to use it
    2. Variants — the different forms the component takes
    3. Usage — do's and don'ts with annotated examples
    4. Specs — sizing, spacing, color, and typography values
    5. Accessibility — keyboard behavior, ARIA roles, and screen reader notes
    6. Code — implementation reference

    Can't find what you need?

    If a pattern or component is missing, check Patterns for composition-level guidance, or open a GitHub issue to propose a new addition to the library.
